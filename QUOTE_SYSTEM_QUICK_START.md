## 🎯 First Steps

### Step 1: Open Dashboard
Navigate to `/admin/quotes-new` in your browser

### Step 2: Explore Existing Quotes
- See your 4 migrated quotes
- Click on any quote to view details
- Try downloading a PDF
- Test the search and filters

### Step 3: Create a Test Quote
1. Click "New Quote"
2. Enter basic info (Step 1)
3. Select a client (Step 2)
4. Add 2-3 line items (Step 4)
5. Preview the PDF
6. Save as draft

### Step 4: Download PDF
- Click the download button on any quote
- PDF generates automatically
- File saves to your downloads folder
