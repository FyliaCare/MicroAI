# Screenshots Directory

## Adding CAGhana Screenshot

To add the CAGhana.com screenshot:

1. Visit https://caghana.com
2. Take a full-page screenshot (recommended tools):
   - **Windows**: Windows Snipping Tool (Win + Shift + S)
   - **Browser Extension**: Full Page Screen Capture
   - **Online Tool**: https://screenshot.guru/

3. **Optimal Screenshot Settings:**
   - Resolution: 1920x1080 or higher
   - Format: JPG or PNG
   - File size: Under 500KB (optimize if needed)
   - Capture: Full homepage view
   - Include: Hero section, main navigation, key services

4. Save the screenshot as: `caghana-screenshot.jpg`
5. Place it in this directory: `public/screenshots/`

The portfolio page is already configured to display the screenshot at:
```tsx
image: '/screenshots/caghana-screenshot.jpg'
```

## Screenshot Optimization Tips

- Use JPG for photos/screenshots (smaller file size)
- Use PNG for graphics with transparency
- Optimize with tools like TinyPNG or Squoosh
- Recommended dimensions: 1200x800px minimum
